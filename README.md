#PS01 - GLitchverse 🎮

**A 2D puzzle-adventure about manipulating the fundamental rules of reality.**

GLitchverse is a game development hackathon project focused on creative environmental manipulation, interactive puzzles, challenging platforming, and exciting combat.

## Core Mechanics

- **Gravity Shift:** Reverse gravity to discover new paths and solve puzzles.
- **Time Freeze:** Freeze selected environmental objects to overcome obstacles.
- **Dimension Shift:** Switch between alternate versions of the world.

## Planned Features

- Four progressively challenging levels
- Interactive puzzles and environmental obstacles
- Enemies and a final boss
- Checkpoints, saving, and level progression
- Glitch Shards currency and an upgrade shop
- Performance scoring and a timer
- Responsive controls and a user-friendly interface

## Development Status

**Current phase:** Initial setup and planning.

All features listed above are planned and have not yet been implemented or tested.
